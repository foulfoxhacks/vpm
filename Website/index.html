How do I add this listing?

Add to VCC opens the VRChat Creator Companion and adds this listing. To add it by hand instead:

  • In the Creator Companion, open Settings, then the Packages tab.
  • Click Add Repository, paste the listing URL above, click Add and confirm.
  • Open a project, choose Manage Project, and add the packages you want.
